# Courier Delivery Management (Варіант 21)

Клієнт-серверна система управління кур'єрською доставкою, реалізована з використанням JavaFX на клієнті та Java Servlet / JDBC / MySQL на сервері. Система підтримує перегляд і CRUD-операції для основних сутностей (`Courier`, `Client`, `Shipment`, `DeliveryOrder`), перевірку предметних правил та фоновий імпорт даних із CSV-файлу.

## Технології
- **Java 21** та **Maven** — збірка модулів і керування залежностями
- **JavaFX** — графічний інтерфейс клієнтського застосунку
- **Servlet API 4.0.1** та **Apache Tomcat 9.x** — обробка HTTP-запитів та розгортання WAR-архіву
- **MySQL** та **JDBC** — зберігання даних у базі
- **Jackson** — серіалізація та десеріалізація JSON
- **JUnit 5** — модульне тестування серверної бізнес-логіки
- **Git** — контроль версій
